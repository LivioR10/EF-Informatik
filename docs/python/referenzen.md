# Listen
## Phänomene
> Eine Liste ist nur sich selbst und man kann sie mit einem = nicht klonen, sonder man hängt nur eine andere Variable an um auf die Liste zu zu greifen.

> Auch hier wieder entseht das Problem dadurch, dass es nur eine eizige Liste ist und alle also der Teil 1,2 und 3 der Matrix alle auf die genau gleiche Liste verweisen. Und somit, wenn man bei der zweiten Liste den mittleren Wert auf 0 ändert wird das dann bei allen anderen, die mit der Liste verbunden sind auch so ausgegeben.
